File format and settings

The window subtitle shows how the file will be saved, for example LF · 4 spaces · UTF-8. An existing file keeps its line endings and indentation.

Format menu

Change Line Endings, Indentation and Tab Width of the current file. A file with mixed line endings is shown as Mixed and is unified when saved.

Defaults and settings

Defaults follow the usual standards of each language (PSR-12 for PHP, gofmt for Go). They can be changed, from lowest to highest priority, in:

  1. your settings: MinorIDE › Settings… (⌘,), tab Formatting, for all languages or one language (stored in settings.json, which Open settings.json shows);
  2. the project: .minoride/settings.json in the project folder;
  3. .editorconfig files.

Changes to any of these files apply to open files at once. A file whose format you changed in the Format menu keeps your choice.

If the text contains characters the file’s encoding can’t store (for example € in ISO-8859-2), MinorIDE asks before saving and offers to save the file in UTF-8 instead.

Tools

MinorIDE › Settings…, tab Tools, shows which external tools (git, go, gopls, php…) were found, with their versions, and how to install a missing one. MinorIDE finds them with the PATH of your login shell, so tools installed with Homebrew work even when MinorIDE is opened from the Finder.

Saving is atomic and keeps file permissions and symbolic links.
