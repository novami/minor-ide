MinorIDE Help

MinorIDE is a native editor for Go and PHP on the Mac, built for speed and a calm, standard macOS feel. It is in early development; this help describes what works today.

  • Files and projects Open folders, tabs, the file tree and changes on disk
  • Editing Multiple cursors, line commands, comments, brackets, folding and split editor
  • Find and replace Find bar, regular expressions and replacing
  • File format and settings Line endings, indentation, encoding, .editorconfig and settings.json
  • Keyboard shortcuts All shortcuts in one table
  • Feedback and support Report a bug, contribute, support the author
