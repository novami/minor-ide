Editing

Multiple cursors and selections

  • ⌥-click adds a cursor; ⌥-drag selects a column.
  • Edit › Select Next Occurrence (⌃G) adds the next match of the selection; ⌃⌘G selects all of them.
  • Esc returns to a single cursor.

Lines

Duplicate Line (⇧⌘D) and Move Line Up/Down (⌥⌘↑ / ⌥⌘↓) work on every selected line.

Comments and brackets

Comment Selection (⌘/) comments or uncomments the selected lines in the comment style of the language. Brackets and quotes are closed for you, typing a closing character steps over it, and selected text gets wrapped. Return between brackets indents the new line. None of this happens inside strings and comments.

Code folding

Click the arrow in the gutter, or use View › Code Folding: fold (⌥⌘←), unfold (⌥⌘→), fold all (⌥⇧⌘←) and unfold all (⌥⇧⌘→).

Wrapping lines

View › Wrap Lines (or Settings › General) turns wrapping on in every editor. A line wraps at the line length from the Format tab (120 characters without it), after a space where possible. The Up and Down arrows and ⌘← / ⌘→ move by rows on screen, ⌃A and ⌃E by whole lines of text. Large and minified files are not wrapped. Lines that do not wrap, and a window narrower than the line length, scroll horizontally (trackpad or scroll bar); the editor also follows the cursor.

Split editor

View › Split Editor Side by Side or Top and Bottom shows the file twice; each part keeps its own cursor and scroll position. ⌥-click a file in the tree to show another file in the other part. ⌘W closes the focused part; the window title, saving and the Format menu follow the focused part.

Syntax colouring

Go, PHP, Latte, NEON, SQL, JSON, JavaScript and TypeScript, CSS and SCSS, HTML, XML and SVG, YAML, shell scripts, Dockerfile, Makefile, .env and Markdown. Colours follow light and dark mode.
